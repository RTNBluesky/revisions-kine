⚙️ L'essentiel

  • Gléno-humérale : 3 degrés de liberté · coude : 2 · poignet : 2 · MCP : 2 · IP : 1 · trapézo-MC : 2.
  • Main céphalique = celle du côté de la tête ; main caudale = celle du côté des pieds.
  • End-feel élastique partout, SAUF : coude flexion/extension = mou ; pronosupination = dur ; déviation radiale = dur.
  • Coiffe des rotateurs = stabilisation dynamique de la gléno-humérale.
  • Règle constante : une main soutient/mobilise, l'autre stabilise.

🎯 Mémo / à retenir

  • Attention : en abduction/adduction horizontale, surveiller la compensation de la scapula.En DL, il y a plus d'instabilité scapulaire.

⚙️ L'essentiel

  • Hanche : 3 DDL · genou : 1 DDL · cheville : 1 DDL.
  • Couverture acétabulaire = 70 % vs 25 % à la gléno-humérale → moins d'amplitude, plus de stabilité.
  • Flexion de hanche active genou tendu = 90° (ischio-jambiers) ; genou fléchi = 125° ; passive = 140°.
  • Inversion = adduction + supination + flexion plantaire ; éversion = abduction + pronation + flexion dorsale.
  • End-feel genou : MOU en flexion, élastique en extension (le seul non élastique du MI).
  • Pour la cheville : le tiers distal de la jambe déborde de la table.

🎯 Mémo / à retenir

  • Précision flexion : active genou tendu 90° (frein ischio-jambiers) · active genou fléchi 125° · passive 140°.
  • Piège d'examen : abduction → EIAS controlatérale ; adduction → EIAS ipsilatérale.
  • INVERSION = adduction + supination + flexion plantaireÉVERSION = abduction + pronation + flexion dorsale
