⚙️ L'essentiel

  • Méthode en 5 temps : Position → Stabiliser → Aligner (axe, bras fixe, bras mobile) → Mouvement → Enregistrer.
  • Référencer un point anatomique = face + ligne/alignement + repère visé.
  • L'axe se place presque toujours sur l'articulation testée ; le bras fixe sur le segment proximal, le bras mobile sur le segment distal.
  • 2 exceptions à retenir : rotations d'épaule (axe = olécrane) et pronosupination (axe = MCP du 3e doigt).
  • CMC du pouce : le goniomètre ne part PAS de 0 → il faut calculer l'amplitude.

🎯 Mémo / à retenir

  • PIÈGE MAJEUR : pour les deux mouvements CMC du pouce, le goniomètre NE PART PAS DE 0 → il faut CALCULER l'amplitude.

⚙️ L'essentiel

  • Hanche flexion/extension et hyperextension : axe = GRAND TROCHANTER, bras fixe = ligne médiane latérale du tronc.
  • Abduction/adduction : axe = EIAS du membre TESTÉ, bras fixe = ligne reliant les 2 EIAS.
  • Rotations de hanche : axe = face antérieure de la PATELLA, bras fixe perpendiculaire au sol.
  • Genou : axe = épicondyle latéral, bras fixe vers le grand trochanter, bras mobile vers la malléole externe.
  • Cheville flexion : axe = malléole externe, bras mobile // 5e métatarsien ; inversion/éversion : axe = point médian entre les malléoles, bras mobile sur le 2e métatarsien.
  • Flexion dorsale : toujours penser au raccourcissement des gastrocnémiens.

🎯 Mémo / à retenir

  • Pourquoi genou fléchi à 30° pour la flexion dorsale ? Pour relâcher les gastrocnémiens (bi-articulaires) et mesurer la vraie amplitude articulaire plutôt qu'une limitation musculaire.

⚙️ L'essentiel

  • Le rachis se mesure au goniomètre ET au ruban — les deux valeurs sont à connaître.
  • Cervical assis · thoraco-lombaire debout, sauf la rotation qui se mesure ASSIS sur une chaise sans dossier.
  • Axe cervical : flexion/extension = méat auditif externe · inclinaison = épineuse de C7 · rotation = sommet de la tête.
  • Repère du ruban : menton ↔ fourchette sternale (flexion/extension) · mastoïde ↔ acromion (inclinaison) · menton ↔ acromion (rotation).
  • Thoraco-lombaire : mesure au ruban = différence T1-S2 entre debout et le mouvement.

🎯 Mémo / à retenir

  • Mémo axes cervicaux : Flexion/Extension = oreille · Inclinaison = C7 · Rotation = sommet du crâne.
