Membre inférieur

Goniométrie — fiche de révision

L'ESSENTIEL

  • Hanche flexion/extension et hyperextension : axe = GRAND TROCHANTER, bras fixe = ligne médiane latérale du tronc.
  • Abduction/adduction : axe = EIAS du membre TESTÉ, bras fixe = ligne reliant les 2 EIAS.
  • Rotations de hanche : axe = face antérieure de la PATELLA, bras fixe perpendiculaire au sol.
  • Genou : axe = épicondyle latéral, bras fixe vers le grand trochanter, bras mobile vers la malléole externe.
  • Cheville flexion : axe = malléole externe, bras mobile // 5e métatarsien ; inversion/éversion : axe = point médian entre les malléoles, bras mobile sur le 2e métatarsien.
  • Flexion dorsale : toujours penser au raccourcissement des gastrocnémiens.

Pourquoi genou fléchi à 30° pour la flexion dorsale ? Pour relâcher les gastrocnémiens (bi-articulaires) et mesurer la vraie amplitude articulaire plutôt qu'une limitation musculaire.

6. Pièges d'examen

  1. Flexion de hanche : bascule postérieure à éviter. Hyperextension : bascule antérieure à éviter.
  2. Adduction : le membre non testé doit être abduit, sinon il bloque le mouvement.
  3. Genou : le patient est en décubitus VENTRAL en position de référence (DD en alternative).
  4. Extension complète du genou → serviette sous la cuisse.
  5. 5e métatarsien pour la flexion plantaire/dorsale ; 2e métatarsien pour l'inversion/éversion.
