Colonne

Mobilisation accessoire — fiche de révision

L'ESSENTIEL

  • Lordose = MOUVEMENT (cervicale, lombaire)Cyphose = PROTECTION (dorsale, sacrée).
  • TEST DE L'ARTÈRE VERTÉBRALE OBLIGATOIRE avant toute mobilisation cervicale. Signes d'alerte = 5 D et 3 N.
  • L'extension + rotation cervicales augmentent la compression de l'artère vertébrale (entrée en C6, foramen transversaire).
  • Passifs = non contractiles (end-feel, schéma capsulaire)Actifs = contractiles (qualité, rythme).
  • Rythme LENT = grades 1-2 (douleur)rythme STACCATO = grades 3-4 (adhérences).
  • Flexion ↑ les trous de conjugaison, extension les ↓.

2. TEST DE L'ARTÈRE VERTÉBRALE — à connaître par cœur

Position : assis, pieds appuyés. Kiné en face.

Étape Durée
Hyperextension cervicale 10-15 s
Pause 10-15 s
Hyperextension + rotation DROITE 10-15 s
Pause 10-15 s
Hyperextension + rotation GAUCHE 10-15 s

Signes d'alerte

Vertiges, nausées, ou tout symptôme d'insuffisance vertébro-basilaire : les 5 D et 3 N + ataxie, hémianesthésie, hémiplégie, altérations de la sensibilité.

➜ INTERRUPTION DU TEST · ➜ CONTRE-INDICATION À LA MOBILISATION ACCESSOIRE

Anatomie de l'artère vertébrale

  • Entre au niveau de C6, passe en arrière des apophyses transverses — foramen transversaire
  • L'EXTENSION (↑ étirement) et la ROTATION (↑ tension du côté opposé) AUGMENTENT LA COMPRESSION
  • Syndrome vertébro-basilaire = compression des artères vertébrales → insuffisance vasculaire cérébrale

5. Mouvements physiologiques — prises

Cervical — actifs avec end-feel (assis)

Mouvement Prise Position du kiné
Flexion (C1-C3 : occiput + menton) End-feel sur occiput et dorsal supérieur De profil
Extension End-feel sur le front et dorsal supérieur De profil
Rotation D/G Main sur l'épaule controlatérale + main sur le menton controlatéral Derrière
Inclinaison D/G Main sur l'épaule controlatérale + main au-dessus de l'oreille controlatérale Derrière

Cervical — passifs (DD, kiné derrière et assis)

  • Flexion/Ext : 2 mains occipitales, ou prise croisée, ou une main mobilise + une stabilise l'épaule
  • Rotation : main occipitale + main sur le menton controlatéral → mouvement vers la main du menton (l'avant-bras soutient la tête en fin d'amplitude)
  • Inclinaison : main sur l'épaule controlatérale + main sur l'occiput

Dorsal — actifs avec end-feel (assis, pieds appuyés)

  • Flexion/Ext : main sur C7 + main lombaire, ou main sur le sternum supérieur + lombaire — kiné de profil
  • Inclinaison : main sur l'épaule homolatérale + main sur le bassin controlatéral — kiné derrière
  • Rotation : main sur le bassin controlatéral + main sur l'épaule controlatérale — kiné derrière, croisant par l'avant

Dorsal supérieur D1-D4 — passifs (DL, genoux fléchis)

On utilise le cervical pour provoquer les mouvements de D1-D4, avec soutien de la tête. Kiné devant, tête du patient à l'oreille, main du patient sous la nôtre.

Inclinaison et rotation UNIQUEMENT vers le côté du dessus → pour l'autre côté, changer de décubitus latéral.

  • Flexion/Ext : une main provoque le mouvement (niveau inférieur de la tête), l'autre palpe les épineuses / espaces interépineux — main sensitive
  • Rotation / Inclinaison : l'autre main palpe les apophyses TRANSVERSES

Dorsal moyen/inférieur D5-D12 — passifs (assis, bras croisés)

Mouvement Passage du bras du kiné Main stabilisatrice
Flexion PAR-DESSUS les bras → épaule controlatérale Lombaire
Extension PAR-DESSOUS les bras → épaule controlatérale Lombaire
Rotation Par-dessus → épaule controlatérale · rotation vers le kiné Bassin controlatéral
Inclinaison Par-dessus → épaule controlatéraleflexion des genoux pour accompagner Bassin controlatéral

Mémo : Extension = par le BAS · Flexion, rotation, inclinaison = par le HAUT.

Amplitudes : flexion 90°, extension 30°, rotation 30°, inclinaison 30°.

Lombaire — actifs debout

  • Flexion : main sur le sacrum + main en C7/D1 → overpressure
  • Extension : main sur le sternum supérieur + sacrum. (Si difficile : table devant, bassin appuyé.)
  • Inclinaison : demander de porter la main au genoustabiliser le bassin controlatéral + main sur l'épaule homolatérale
  • Rotation : kiné derrière, stabilise le bassin avec le sienmain bassin controlatéral + main épaule controlatérale
  • Déviations latérales (« danse du ventre ») : bassin stable
  • Mouvements combinés (actifs seuls, sans end-feel) : typiques des lordoses, utiles pour reproduire la symptomatologie

RÈGLE CLÉ : la FLEXION augmente les trous de conjugaison ; l'EXTENSION les diminue.

Lombaire — passifs

  • DD : soutenir les MI (main sous le 1er genou jusqu'au 2e) → flexion, inclinaison latérale, rotation · mouvement vers le kiné, main céphalique sur le bassin
  • DL : MI fléchis soutenus par la table, pieds en dehors → inclinaison latérale en élevant les pieds vers le haut

8. Questions d'auto-évaluation

  1. Décrire le test de l'artère vertébrale (positions et durées) et ses signes d'alerte.
  2. Pourquoi l'extension et la rotation compriment-elles l'artère vertébrale ?
  3. Que révèlent les mouvements passifs vs actifs ?
  4. Quel rythme pour la douleur ? Pour les adhérences ?
  5. Pour D1-D5, où se place le kiné ? Et pour D6-D12 ?
  6. Quand utiliser les PAU plutôt que les PAC ?
  7. Quel effet a la flexion sur les trous de conjugaison ?
  8. Différencier compression et décompression sacro-iliaque (contact et position du coude).
  9. Pourquoi les mouvements accessoires doivent-ils être générés par le corps du kiné et non par ses bras ?
