⚙️ Mécanismes (flèches)

  • Bouche : ingestion + mastication + amylase salivaire → bolus
  • Œsophage : déglutition + péristaltisme → estomac
  • Estomac : pepsine + HCl + chyme + pompe pylorique → duodénum
  • Pancréas + bile → neutralisation pH (NaHCO₃) + lipases + amylase
  • Intestin grêle : digestion complète + absorption (villosités)
  • Foie : détox + glycogène + biotransformation + bile
  • Côlon : absorption eau/ions + mouvements de masse 3-4×/jour

🎯 À ne pas confondre

  • Bolus (bouche) ≠ chyme (estomac)
  • Veine porte = nutriments → foie AVANT circulation systémique
  • Foie = stockage + détox + bile + phagocytose (multi-fonction)

⚙️ Mécanismes

  • 3 lignes de défense : tampons → respi → rein
  • Tampons : secondes (HCO₃⁻ / phosphate / protéines / Hb)
  • Respi : minutes · contrôle 75% des variations (CO₂ ↔ fréquence)
  • Rein : 24-48h · excrète H⁺ + réabsorbe HCO₃⁻
  • Acidose métabolique → hyperventilation (Kussmaul)
  • Alcalose → hypoventilation
  • Alcalose → ↓ Ca²⁺ libre → tétanie

🎯 ROME pour interpréter

  • Respi = Opposé (pH ↑ = CO₂ ↑)
  • Métabo = Égal (pH ↑ = HCO₃⁻ ↑)
  • Acidose → dépression SNC (coma)
  • Alcalose → excitation SNC (tétanie)

⚙️ Mécanismes

  • 3 voies ATP : PCr (≤20 s) → glycolyse (2 ATP) → aérobie (36-38 ATP)
  • Glycolyse : glucose → 2 pyruvate + 2 ATP + 2 NADH (cytoplasme)
  • Aérobie : pyruvate → acétyl-CoA → Krebs → chaîne respi → ATP synthase
  • Rendement aérobie ≈ 40% (reste en chaleur)
  • QR ≈ 1,0 → glucides · QR ≈ 0,71 → lipides
  • Entraînement → conversion fibres + ↑ mito
