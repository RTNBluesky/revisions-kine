Myologie — Ceinture scapulaire, Épaule, Coude, Avant-bras

1. Muscles de la ceinture scapulaire (6)

Trapèze

  • Origine : ligne courbée occipitale sup., ligament nucal, épineuses C7-T12
  • Insertion : 1/3 externe clavicule, acromion, épine de la scapula 🖼
  • Action :
    • Fibres supérieures : élévation + rotation supérieure de la scapula
    • Fibres moyennes : adduction (rétraction) de la scapula
    • Fibres inférieures : dépression + rotation supérieure
    • Toutes : stabilisation et rétraction
  • Innervation : nerf accessoire (XI) + racines C3-C4

Élévateur de la scapula (levator scapulae)

  • Origine : apophyses transverses C1-C4
  • Insertion : angle supérieur de la scapula
  • Action : élévation + rotation inférieure de la scapula
  • Innervation : nerf scapulaire dorsal (C5) + C3-C4

Rhomboïdes (petit + grand)

  • Origine : épineuses C7-T5 (petit : C7-T1 ; grand : T2-T5)
  • Insertion : bord interne de la scapula
  • Action : élévation + adduction (rétraction) + rotation inférieure
  • Innervation : nerf scapulaire dorsal (C5)

Dentelé antérieur (Serratus antérieur)

  • Origine : côtes 1-8/9 (surface antérolatérale)
  • Insertion : bord interne de la scapula (surface antérieure)
  • Action : protraction de la scapula, rotation supérieure, stabilisation
  • Innervation : nerf long thoracique (C5-C7)

Petit pectoral

  • Origine : côtes 3-5 (face antérieure)
  • Insertion : processus coracoïde
  • Action : « tilt » antérieur (protraction + dépression)
  • Innervation : nerf pectoral médial (C8-T1)

Sous-clavier

  • Origine : 1ère côte
  • Insertion : partie inférieure de la clavicule
  • Action : dépression de la clavicule, stabilisation sterno-claviculaire 🖼
  • Innervation : nerf sous-clavier (C5-C6)

2. Muscles de l'épaule (9)

Deltoïde

  • Origine : 1/3 latéral clavicule, acromion, épine de la scapula
  • Insertion : tubérosité deltoïdienne (V deltoïdien) de l'humérus
  • Action :
    • Toutes : abduction de l'humérus
    • Antérieures : flexion, rotation interne, adduction horizontale
    • Postérieures : extension, rotation externe, abduction horizontale
  • Innervation : nerf axillaire (C5-C6)

Supra-épineux (sus-épineux)

  • Origine : fosse supra-épineuse de la scapula
  • Insertion : trochiter (face supérieure)
  • Action : abduction de l'humérus, stabilisation
  • Innervation : nerf supra-scapulaire (C5)

Infra-épineux (infraspinatus)

  • Origine : fosse infra-épineuse
  • Insertion : trochiter (face postérieure)
  • Action : rotation externe, stabilisation
  • Innervation : nerf supra-scapulaire (C5-C6)

Petit rond (teres minor)

  • Origine : bord latéral de la scapula
  • Insertion : trochiter (face postérieure)
  • Action : rotation externe, stabilisation
  • Innervation : nerf axillaire (C5)

Sous-scapulaire (subscapulaire)

  • Origine : fosse sub-scapulaire
  • Insertion : trochin (face antérieure)
  • Action : rotation interne, stabilisation
  • Innervation : nerf sous-scapulaire 🖼 (C5-C6)

Grand pectoral

  • Origine : chef claviculaire (1/2 interne clavicule) + chef sterno-costal (sternum + cartilages 1-6)
  • Insertion : sillon intertuberculaire (lèvre interne)
  • Action : adduction + rotation interne de l'humérus, flexion (fibres sup.), extension (à partir de la flexion)
  • Innervation : nerf pectoral latéral (C5-C7) + nerf pectoral médial (C8-T1)

Coraco-brachial

  • Origine : processus coracoïde
  • Insertion : face interne de la diaphyse humérale
  • Action : flexion + adduction de l'humérus
  • Innervation : nerf musculo-cutané (C6-C7)

Grand dorsal

  • Origine : épineuses T6-T12 + L1-L5, sacrum, crête iliaque post., fascia lombaire, côtes 9-12
  • Insertion : sillon intertuberculaire (lèvre interne)
  • Action : extension, adduction, rotation interne de l'humérus
  • Innervation : nerf thoraco-dorsal (C6-C7-C8)

Grand rond (teres major)

  • Origine : angle inférieur et bord latéral inf. de la scapula
  • Insertion : sillon intertuberculaire (lèvre interne)
  • Action : extension, adduction, rotation interne
  • Innervation : nerf sous-scapulaire (C5-C6)

COIFFE DES ROTATEURS : Supra-épineux + Infra-épineux + Petit rond + Sous-scapulaire (mnémo : SITS)

3. Muscles du coude et avant-bras (8)

Biceps brachial

  • Origine : chef long (tubercule supra-glénoïdien), chef court (coracoïde)
  • Insertion : tubérosité radiale + aponévrose bicipitale
  • Action : flexion (épaule + coude 🖼), supination (RU). Chef court aide à l'abduction horizontale GH
  • Innervation : nerf musculo-cutané (C5-C6)

Brachial antérieur

  • Origine : humérus, face antérieure, 1/2 distale
  • Insertion : tubérosité ulnaire + processus coronoïde
  • Action : flexion du coude (HU)
  • Innervation : musculo-cutané (C5-C6)

Brachio-radial

  • Origine : crête supracondylienne latérale de l'humérus
  • Insertion : processus styloïde du radius
  • Action : flexion du coude (surtout position neutre), aide la prono/supination
  • Innervation : nerf radial (C5-C6)

Rond pronateur

  • Origine : épicondyle médial + processus coronoïde
  • Insertion : corps médian du radius
  • Action : pronation, aide la flexion
  • Innervation : nerf médian (C6-C7)

Carré pronateur

  • Origine : partie antérieure distale du cubitus
  • Insertion : partie antérieure distale du radius
  • Action : pronation
  • Innervation : nerf médian (C8-T1)

Triceps brachial

  • Origine : long chef (tubercule infra-glénoïdien), latéral (humérus post. prox.), médial (humérus post. distal)
  • Insertion : olécrane du cubitus
  • Action : extension du coude. Long chef : extension de l'épaule + adduction
  • Innervation : nerf radial (C7-C8)

Anconé

  • Origine : épicondyle latéral postérieur
  • Insertion : olécrane + face postérieure proximale du cubitus
  • Action : aide extension + stabilisation
  • Innervation : radial (C7-C8, T1)

Supinateur

  • Origine : épicondyle latéral + cubitus proximal post.
  • Insertion : radius proximal latéral
  • Action : supination (RU)
  • Innervation : nerf radial (C6)
