Myologie — Colonne, Thorax, Abdomen, Respiration

1. Muscles superficiels du dos

Trapèze (déjà décrit avec scapula)

  • Origine : ligne nuchale supérieure, ligament nuchal, épineuses C7-T12
  • Insertion : 1/3 externe clavicule, acromion, épine de la scapula
  • Action : élève / rétracte / abaisse la scapula (selon les fibres)
  • Innervation : nerf XI + C3-C4

Grand dorsal

  • Origine : épineuses T6-L5, sacrum, crête iliaque post., côtes 9-12, fascia lombaire
  • Insertion : sillon intertuberculaire de l'humérus
  • Action : extension, adduction, rotation interne de l'épaule
  • Innervation : nerf thoraco-dorsal (C6-C8)

2. Muscles spinaux (érecteurs du rachis)

Erector spinae (3 colonnes parallèles)

  • Ilio-costal (latéral) — côtes
  • Longissimus (intermédiaire) — apophyses transverses
  • Épineux (médial) — apophyses épineuses

Origine commune : sacrum, crête iliaque, épineuses lombaires/thoraciques basses.

Action :

  • Bilatérale : extension du rachis
  • Unilatérale : inclinaison homolatérale + rotation

Innervation : rameaux postérieurs des nerfs spinaux.

3. Muscles profonds (transverso-épineux)

Semi-épineux

Apophyses transverses → épineuses (4-6 niveaux). Extension + rotation controlatérale.

Multifidus

Apophyses transverses → épineuses (2-3 niveaux). Extension + rotation controlatérale + stabilisation.

Rotateurs

1-2 niveaux. Rotation.

4. Muscle carré des lombes

  • Origine : crête iliaque + ligament ilio-lombaire
  • Insertion : 12e côte + apophyses transverses L1-L4
  • Action : inclinaison latérale du tronc, fixation 12e côte (inspiration), extension lombaire
  • Innervation : T12 + plexus lombaire (L1-L3)

5. Diaphragme — muscle inspiratoire principal

  • Origine : 3 parties :
    • Sternale : face postérieure du processus xiphoïde
    • Costale : faces internes des côtes 7-12
    • Lombaire : corps L1-L3 par 2 piliers (droit + gauche)
  • Insertion : centre phrénique (tendineux)
  • Action : inspiration (abaissement de la coupole, augmentation des diamètres verticaux du thorax)
  • Innervation : nerf phrénique (C3-C5)

Orifices du diaphragme

  • Orifice aortique : T12 — aorte, conduit thoracique
  • Orifice œsophagien : T10 — œsophage, nerfs vagues (X)
  • Orifice de la veine cave : T8 — veine cave inférieure

6. Muscles intercostaux

Intercostaux externes (11 paires)

  • Direction : oblique en bas et en avant
  • Action : inspiration (élèvent les côtes)
  • Innervation : nerfs intercostaux

Intercostaux internes

  • Direction : oblique en bas et en arrière
  • Action : expiration forcée (abaissent les côtes)

Intercostaux intimes

Profonds, fonction identique aux internes.

7. Autres muscles de la respiration

Muscles inspiratoires accessoires

  • SCM
  • Scalènes
  • Petit pectoral
  • Grand pectoral
  • Dentelé antérieur

Muscles expiratoires (forcée)

  • Muscles abdominaux
  • Intercostaux internes
  • Carré des lombes

8. Muscles abdominaux

Grand droit de l'abdomen

  • Origine : pubis (symphyse + épine)
  • Insertion : 5e-7e cartilages costaux + processus xiphoïde
  • Action : flexion du tronc, augmente la pression intra-abdominale
  • Innervation : nerfs intercostaux T6-T12

Oblique externe

  • Origine : faces externes des côtes 5-12
  • Insertion : crête iliaque + ligne blanche
  • Action :
    • Bilatérale : flexion du tronc
    • Unilatérale : inclinaison homolatérale + rotation controlatérale
  • Innervation : T7-T12

Oblique interne

  • Origine : crête iliaque + ligament inguinal + fascia thoraco-lombaire
  • Insertion : 10-12e côtes + ligne blanche
  • Action :
    • Bilatérale : flexion du tronc
    • Unilatérale : inclinaison + rotation homolatérale

Transverse de l'abdomen

  • Le plus profond
  • Action : comprime l'abdomen, expiration forcée, stabilité du tronc (« gaine abdominale »)

9. Synthèse — Respiration

Inspiration calme : diaphragme + intercostaux externes
Inspiration forcée : + SCM, scalènes, pectoraux, dentelé ant.
Expiration calme : passive (élasticité)
Expiration forcée : abdominaux + intercostaux internes
