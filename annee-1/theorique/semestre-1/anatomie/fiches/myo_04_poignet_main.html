Myologie — Poignet et Main

1. Muscles fléchisseurs du poignet et des doigts

Fléchisseur radial du carpe (Flexor Carpi Radialis - FCR)

  • Origine : épicondyle médial de l'humérus
  • Insertion : bases des métacarpiens 2 et 3 (face palmaire)
  • Action : flexion du poignet + déviation radiale
  • Innervation : nerf médian (C6-C7)

Long palmaire (Palmaris Longus)

  • Origine : épicondyle médial
  • Insertion : aponévrose palmaire (fascia palmaire)
  • Action : flexion du poignet, tension du fascia palmaire
  • Innervation : nerf médian (C6-C7)

Fléchisseur ulnaire du carpe (Flexor Carpi Ulnaris - FCU)

  • Origine : épicondyle médial + partie proximale postérieure du cubitus
  • Insertion : pisiforme, hamatum, 5e métacarpien
  • Action : flexion + déviation ulnaire (cubitale) du poignet
  • Innervation : nerf ulnaire (C8-T1)

Fléchisseur superficiel des doigts (FDS)

  • Origine : épicondyle médial + processus coronoïde + diaphyse antérieure du radius
  • Insertion : phalanges moyennes des doigts 2-5 (tendon bifurqué)
  • Action : flexion des doigts (IFP + MP), flexion du poignet
  • Innervation : nerf médian (C7-C8-T1)

Fléchisseur profond des doigts (FDP)

  • Origine : moitié proximale du cubitus (ant. + médiale) + membrane interosseuse
  • Insertion : bases des phalanges distales 2-5 (face palmaire)
  • Action : flexion des doigts (IFD + IFP + MP), aide flexion poignet — fermer le poing serré
  • Innervation : Médian (doigts 2-3) + Ulnaire (doigts 4-5)

2. Muscles extenseurs du poignet et des doigts

Long extenseur radial du carpe (ECRL)

  • Origine : crête supracondylienne latérale
  • Insertion : base du métacarpien 2 (côté dorsal)
  • Action : extension + déviation radiale du poignet ; aide flexion coude
  • Innervation : nerf radial (C6-C7)

Court extenseur radial du carpe (ECRB)

  • Origine : épicondyle latéral
  • Insertion : base du métacarpien 3 (côté dorsal)
  • Action : extension + déviation radiale
  • Innervation : nerf radial (C6-C7)

Extenseur ulnaire du carpe (ECU)

  • Origine : épicondyle latéral + corps postérieur médial du cubitus
  • Insertion : base du métacarpien 5 (côté dorsal/ulnaire)
  • Action : extension + déviation ulnaire du poignet
  • Innervation : nerf radial (C6-C7-C8)

Extenseur commun des doigts (EDC)

  • Origine : épicondyle latéral
  • Insertion : bases phalanges distale + proximale des doigts 2-5 (côté dorsal)
  • Action : extension poignet + extension doigts (AIP, AID, MP)
  • Innervation : nerf radial (C6-C7-C8)

3. Muscles du pouce (extrinsèques)

Long fléchisseur du pouce (Flexor Pollicis Longus - FPL)

  • Origine : surface antérieure du radius + membrane interosseuse
  • Insertion : base phalange distale du pouce (palmaire)
  • Action : flexion du pouce
  • Innervation : nerf médian (C8-T1)

Long abducteur du pouce (APL)

  • Origine : cubitus + radius postérieurs + membrane interosseuse
  • Insertion : base du métacarpien 1
  • Action : abduction + extension du pouce (CMC), déviation radiale poignet
  • Innervation : nerf radial (C7-C8)

Long extenseur du pouce (EPL)

  • Origine : partie médiane et postérieure cubitus + membrane interosseuse
  • Insertion : base phalange distale du pouce
  • Action : extension du pouce (IP, MP, CM)
  • Innervation : nerf radial (C6-C7-C8)

Court extenseur du pouce (EPB)

  • Origine : partie distale postérieure du radius + membrane interosseuse
  • Insertion : base phalange proximale (côté dorsal)
  • Action : extension du pouce (MP, CM)
  • Innervation : nerf radial (C7-C8)

4. Muscles intrinsèques de la main

Éminence thénar (muscles du pouce, courts)

  • Court fléchisseur du pouce (FPB) — flexion pouce — médian + ulnaire
  • Court abducteur du pouce (APB) — abduction pouce — médian
  • Opposant du pouce — opposition du pouce (abd + flex + rotation CMC #1) — médian

Éminence hypothénar (muscles du 5e doigt)

Tous innervés par le nerf ulnaire (C8-T1) :

  • Abducteur du petit doigt — abduction du 5e doigt
  • Court fléchisseur du petit doigt — flexion du 5e
  • Opposant du petit doigt — opposition du 5e

Adducteur du pouce

  • Origine : métacarpien 3 + os capité + bases métacarpiens 2 et 3
  • Insertion : base phalange proximale (côté ulnaire)
  • Action : adduction du pouce
  • Innervation : nerf ulnaire (C8-T1)

Interosseux palmaires (3 muscles, profonds)

  • Origine : métacarpiens 2, 4, 5 (côté ulnaire)
  • Insertion : phalange proximale doigts 2, 4, 5 + extensions tendineuses dorsales
  • Action : ADduction des doigts (vers le 3e doigt). Flexion MP + extension IP
  • Innervation : nerf ulnaire (C8-T1)

Interosseux dorsaux (4 muscles)

  • Origine : diaphyses métacarpiens 2, 4, 5
  • Insertion : phalange proximale doigts 2, 4, 5 (+ extensions dorsales)
  • Action : ABduction des doigts (à partir du 3e). Flexion MP + extension IP
  • Innervation : nerf ulnaire
Mnémo : DAB / PAD : Dorsal Abduct, Palmar Adduct

Lombricaux (4 muscles)

  • Origine : 4 tendons du fléchisseur profond des doigts
  • Insertion : 4 tendons de l'extenseur commun (extensions digitales dorsales)
  • Action : flexion MP + extension IP des doigts 2-5
  • Innervation : doigts 2-3 médian / doigts 4-5 ulnaire
