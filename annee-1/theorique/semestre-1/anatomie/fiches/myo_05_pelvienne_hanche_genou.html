Myologie — Ceinture pelvienne, Hanche, Genou

1. Muscles de la hanche — Partie 1 (extenseurs/rotateurs)

Gluteus maximus (grand fessier)

  • Origine : crête iliaque, ilium, sacrum (+ coccyx, ligament sacro-tubéreux)
  • Insertion : tubérosité glutéale du fémur + bande iliotibiale
  • Action : extension + rotation externe de la hanche. Fibres inf. : adduction. Fibres sup. : abduction
  • Innervation : nerf glutéal inférieur (L5, S1, S2)

Gluteus medius (moyen fessier)

  • Origine : face supéro-latérale de l'ilium
  • Insertion : grand trochanter
  • Action : abduction de la hanche. Fibres ant. : flexion + RI. Fibres post. : extension + RE
  • Innervation : nerf glutéal supérieur (L4, L5, S1)

Gluteus minimus (petit fessier)

  • Origine : face inféro-latérale de l'ilium (sous le moyen fessier)
  • Insertion : grand trochanter
  • Action : abduction + rotation interne
  • Innervation : nerf glutéal supérieur (L4, L5, S1)

Rotateurs profonds (6 muscles)

Tous ont pour action commune la rotation externe de la hanche, insertion sur le grand trochanter.

  • Piriforme (pyramidal) — sacrum antérieur → grand trochanter — plexus sacré (S1, S2)
  • Gemellus supérieur — ischium → grand troch. — plexus sacré (L5, S1, S2)
  • Obturateur interne — foramen obturateur (interne) → grand troch. — plexus sacré (L5, S1, S2)
  • Gemellus inférieur — ischium → grand troch. — plexus sacré (L4, L5, S1)
  • Obturateur externe — foramen obturateur (externe) → grand troch. — nerf obturateur (L3, L4)
  • Carré fémoral — ischium → grand troch. — plexus sacré (L4, L5, S1)

Iliaque

  • Origine : fosse iliaque antérieure (face interne ilion)
  • Insertion : petit trochanter
  • Action : flexion de la hanche. Si fémur fixe (debout) : inclinaison pelvienne antérieure
  • Innervation : nerf fémoral (L2, L3)

Psoas

  • Origine : corps + processus transverses T12 et L1-L5
  • Insertion : petit trochanter
  • Action : flexion de la hanche. Si fémur fixe : inclinaison pelvienne ant. + lordose lombaire
  • Innervation : plexus lombaire (L2-L4)
Iliopsoas = iliaque + psoas, fléchisseur principal de la hanche.

2. Muscles de la hanche — Partie 2 (adducteurs et autres)

Sartorius (couturier)

  • Origine : EIAS
  • Insertion : face interne du tibia proximal (tendon de la patte d'oie / pes anserinus)
  • Action : flexion + abduction + rotation externe de la hanche ; flexion + rotation interne du genou
  • Innervation : nerf fémoral (L2, L3)

Tensor fascia latae (TFL)

  • Origine : crête iliaque, postérieur à l'EIAS
  • Insertion : condyle latéral du tibia (via tractus iliotibial)
  • Action : flexion + abduction + rotation interne hanche ; stabilisation genou en extension
  • Innervation : nerf glutéal supérieur (L4, L5, S1)

Pectiné

  • Origine : branche supérieure du pubis
  • Insertion : ligne pectinée du fémur
  • Action : flexion + adduction + rotation interne de la hanche
  • Innervation : nerf fémoral (L2, L3)

Adducteur court

  • Origine : branche inférieure du pubis
  • Insertion : ligne âpre proximale
  • Action : flexion + adduction + rotation interne hanche
  • Innervation : nerf obturateur (L2-L4)

Adducteur long

  • Origine : tubercule pubien
  • Insertion : ligne âpre médiane
  • Action : flexion + adduction + rotation interne hanche
  • Innervation : nerf obturateur (L2-L4)

Adducteur magnus (grand adducteur)

  • Origine : fibres antérieures (br. inf. pubis), fibres postérieures (br. ischium), fibres ischio-condylaires (tubérosité ischiatique)
  • Insertion : ligne âpre complète + tubercule de l'adducteur
  • Action :
    • Toutes : adduction
    • Antérieures : flexion + RI
    • Postérieures : extension de la hanche
  • Innervation : nerf obturateur (L2-L4) + nerf sciatique (L4, L5, S1) (double innervation)

Gracile (droit interne)

  • Origine : branche inférieure du pubis
  • Insertion : tibia proximal interne (patte d'oie)
  • Action : adduction hanche ; flexion + RI du genou (en flexion)
  • Innervation : nerf obturateur (L2, L3)
Patte d'oie (pes anserinus) : Sartorius + Gracile + Semi-tendineux. Mnémo : SGS ou « Say Grace before Tea ».

3. Muscles du genou

Quadriceps (4 chefs - extenseurs)

Tous innervés par le nerf fémoral (L2-L4). Tous s'insèrent sur la tubérosité tibiale antérieure via le ligament rotulien.

1. Droit fémoral (rectus femoris)

  • Origine : EIAI
  • Action : extension du genou + flexion de la hanche (biarticulaire)

2. Vaste latéral

  • Origine : fémur postérieur + latéral, ligne âpre latérale
  • Action : extension du genou

3. Vaste intermédiaire

  • Origine : diaphyse fémorale antérieure + latérale
  • Action : extension du genou

4. Vaste médial

  • Origine : ligne âpre médiale
  • Action : extension du genou

Ischio-jambiers (3 muscles - fléchisseurs)

Biceps fémoral

  • Origine : chef long (tubérosité ischiatique), chef court (ligne âpre distale)
  • Insertion : tête du péroné
  • Action : flexion + rotation latérale du genou. Chef long : extension + RE hanche
  • Innervation : nerf sciatique - partie tibiale (long chef) + partie péronière (court chef)

Semi-tendineux

  • Origine : tubérosité ischiatique
  • Insertion : tibia proximal interne (patte d'oie)
  • Action : flexion + rotation médiale du genou ; extension + RI hanche
  • Innervation : partie tibiale du sciatique (L5-S2)

Semi-membraneux

  • Origine : tubérosité ischiatique
  • Insertion : condyle postérieur médial du tibia
  • Action : flexion + rotation médiale du genou ; extension + RI hanche
  • Innervation : partie tibiale du sciatique (L5-S2)

Poplité

  • Origine : condyle latéral du fémur
  • Insertion : tibia proximal postéro-médial
  • Action : rotation médiale du genou. Débloque le genou en extension
  • Innervation : nerf tibial (L4, L5, S1)
