Complexe articulaire de l'épaule

Cours 6 — fiche de révision

L'essentiel

  • Flexion 180° / extension. Abduction 180° / adduction. Rotation interne 70° / externe 90°.
  • Ligaments : gléno-huméraux, coraco-huméral, coraco-acromial.
  • Tendon du long biceps : intra-articulaire, recentre la tête.
  • Coiffe des rotateurs (« ligaments actifs ») : SISP = Supra-épineux, Infra-épineux, Petit rond, Subscapulaire.
  • Ratio 2:1 GH:scapula → 120° GH + 60° rotation supérieure scapulaire.
  • Clavicule : 25° élévation SC + 35° rotation AC.
  • 0–30° (abd) / 0–60° (flex) : phase stationnaire scapulaire. Deltoïde + supra-épineux ; coiffe = fixation tête humérale.

1 · Vue d'ensemble

4 os : thorax, clavicule, scapula, humérus. 3 articulations synoviales + 1 mécanisme de glissement musculaire.

2 · Amplitudes GH

  • Flexion 180° / extension. Abduction 180° / adduction. Rotation interne 70° / externe 90°.

3 · Éléments de stabilité GH

  • Labrum glénoïdien : ↑ congruence.
  • Ligaments : gléno-huméraux, coraco-huméral, coraco-acromial.
  • Tendon du long biceps : intra-articulaire, recentre la tête.
  • Coiffe des rotateurs (« ligaments actifs ») : SISP = Supra-épineux, Infra-épineux, Petit rond, Subscapulaire.
Stabilité de l'épaule : architecture osseuse faible (–), capsulo-ligamentaire ±, musculo-tendineuse +++ → stabilité dynamique.

6 · Rythme scapulo-huméral (180° d'élévation)

  • Ratio 2:1 GH:scapula → 120° GH + 60° rotation supérieure scapulaire.
  • Clavicule : 25° élévation SC + 35° rotation AC.
  1. 0–30° (abd) / 0–60° (flex) : phase stationnaire scapulaire. Deltoïde + supra-épineux ; coiffe = fixation tête humérale.
  2. 30/60–80–100° : début ceinture scapulaire ; trapèze sup. + grand dentelé + rhomboïdes ; tension du lig. costo-claviculaire en fin.
  3. 120–150° : rotation externe humérale, scapula mobile indépendamment, trapèze inf. ajoute la rotation sup.
  4. Fin d'élévation : GH redomine, AC pivote ; trapèze sup. stabilise verticalement.
Altération du rythme scapulo-huméral → ↓ espace sous-acromial → conflit (impingement) entre tête humérale et acromion.

7 · Rôles musculaires clés

  • Deltoïde = mobilisateur GH dans tous les mouvements.
  • Grand dentelé + trapèze = couple force pour rotation supérieure de la scapula.
  • Coiffe = recentrage de la tête humérale + rotation externe.
