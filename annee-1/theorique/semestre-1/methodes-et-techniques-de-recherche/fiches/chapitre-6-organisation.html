Chapitre 6 — Organisation du travail de recherche

Structure des mémoires, articles, thèses · Pré-textuels / Textuels / Post-textuels

1. Pourquoi l'organisation compte

En santé, l'organisation n'est pas un détail esthétique : c'est ce qui permet au lecteur (enseignant, jury, pair) de :

  • Comprendre rapidement la logique du travail
  • Trouver facilement une information
  • Juger la qualité scientifique

2. Les 3 grandes parties

PartieContenu
Pré-textuelsCouverture · Page de garde · Dédicace · Résumé/abstract · Abréviations · Index
Textuels (cœur)Introduction · Revue de littérature · Méthodologie · Résultats · Discussion · Conclusion
Post-textuelsBibliographie · Appendices · Annexes

3. Éléments pré-textuels

Couverture

Formelle, sobre, lisible. Contient : titre complet, nom étudiant, institution/cursus/année, lieu et date, nom de l'orienteur, parfois logo.

  • Travaux de recherche : petite image admise (silhouette, schéma articulation)
  • Article/Monographie/Projet : pas d'image

Titre

Bon titre = simple, précis, attractif
Structure idéale :

Population + Condition + Intervention/Variable


Ex. : « Effet d'un programme d'exercices excentriques chez les coureurs atteints de tendinopathie d'Achille »

Résumé / Abstract (très important)

ContenuCaractéristiques
Contexte (2-3 phrases)
Objectifs
Méthodologie (type, population, outils)

Conclusion + implication clinique		100–150 mots

Mots-clés (keywords)

  • 3 à 6 mots
  • Spécifiques (éviter les termes génériques comme « therapy »)
  • Idéalement alignés avec des MeSH terms

Abréviations vs Acronymes

AbréviationsAcronymes

Règle fondamentale : toute abréviation/sigle doit être

définie la première fois

dans le texte.

Index / Sommaire

  • Liste chapitres et sous-chapitres
  • Reflète la structure réelle (n° de pages à jour)
  • Obligatoire pour mémoires/thèses, pas pour les articles courts
  • Utiliser les styles Word (Titre 1, 2, 3) pour génération auto

4. Éléments textuels — le cœur scientifique

Introduction

Elle doit :

  • Situer le contexte (épidémio, impact)
  • Présenter le problème spécifique
  • Justifier le choix du sujet (pertinence, lacunes)
  • Formuler la question
  • Présenter les objectifs (général + spécifiques)
  • Donner un bref aperçu de la méthodologie
  • Annoncer la structure du document

Conseil : rédiger l'introduction après la discussion/conclusion (cohérence).

Revue de littérature

Ce n'est PAS un enchaînement de copier-coller. C'est une

synthèse organisée et critique

  • : Comparer les résultats
  • Souligner convergences / divergences
  • Pointer les limites des études existantes

Organiser par thèmes (douleur, fonction, adhésion…) et non étude par étude.

Méthodologie

Doit détailler : question, objectifs, hypothèses, variables (VI/VD/confondantes), population/échantillon, instruments, procédures, traitement des données, aspects éthiques.

→ permet la reproductibilité

Résultats

Règle d'or : on

décrit

, on ne

commente pas

.
L'interprétation va dans la Discussion.
Chaque tableau/figure doit être mentionné dans le texte.

Discussion (structure type)

  1. Résultat principal → comparaison avec études X, Y, Z
  2. Interprétation
  3. Limites éventuelles
  4. Implication clinique

Conclusion

  • Répond à la question de recherche
  • Reprend les objectifs
  • Synthétise les apports
  • Mentionne les limites
  • Suggère des pistes futures

Éviter les conclusions trop fortes. Préférer : « Les résultats suggèrent que… » plutôt que « Il est prouvé que… ».

5. Éléments post-textuels

Bibliographie

  • Liste complète des sources utilisées et citées
  • Selon norme (APA, Vancouver…)
  • Livres, articles, sites sérieux, guidelines
  • Tout ce qui est cité → bibliographie (et inversement)

Appendices vs Annexes

AppendicesAnnexes
Matériel créé/adapté par les auteursMatériel non créé par les auteurs (externe)
Ex. : questionnaires construits, grilles d'observation, instructionsEx. : version originale du SF-36, brochure officielle, autorisations

Chaque appendice/annexe : page-titre, numérotation claire (Appendice I, II…), référencé dans le texte.

6. Types de documents

TypeStructure
Document de rechercheStructure complète (couverture, page de titre, index, intro, revue, méthodes, résultats, discussion, conclusions, biblio, annexes). Typique mémoires.
ArticleFormat raccourci standardisé : Titre – Abstract – Intro – Méthodes – Résultats – Discussion – Conclusion – Références. Limite de mots.
ThèseStructure complète + originalité + volume + rigueur extrême. Souvent plusieurs études.

Toujours vérifier les normes spécifiques de l'institution ou de la revue (auteurs, nb de mots, style de références).

🎯 À retenir absolument

  • 3 parties : pré-textuel / textuel / post-textuel
  • Textuel = Intro → Revue litt → Méthodo → Résultats → Discussion → Conclusion
  • Résumé = 100-150 mots, rédigé en dernier, autonome
  • Keywords : 3-6, alignés MeSH
  • Abréviations : définir à la 1ʳᵉ apparition
  • Résultats = décrire · Discussion = interpréter
  • Appendices (créés par auteurs) ≠ Annexes (externes)
  • Article = court · Mémoire = complet · Thèse = + originalité
