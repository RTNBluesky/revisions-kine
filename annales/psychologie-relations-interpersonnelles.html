(Q5) Les composantes de l'expérience émotionnelle selon Parkinson, Fischer et Manstead (2005) sont :

  • 1) Cause ; évaluation ; expression ; changements corporels et faciaux ; régulation ; contexte
  • 2) Évaluation ; expression ; relation ; changements physiologiques ; tendances à l'action ; régulation
  • 3) Évaluation ; cause ; changements physiologiques ; régulation ; expression ; tendances à l'action
Corrigé proposé

Réponse : la 2e proposition. Évaluation (appraisal), expression, relation, changements physiologiques, tendances à l'action et régulation. Pour ces auteurs, l'émotion se joue aussi dans la relation sociale.

2

(Q7) Les 4 compétences du modèle d'intelligence émotionnelle de Salovey et Mayer sont :

  • 1) Utiliser les émotions ; comprendre les émotions ; réguler les émotions ; identifier les émotions 2) Utiliser les émotions ; comprendre les émotions ; exprimer les émotions ; identifier les émotions
  • 3) Identifier les émotions ; utiliser les émotions ; comprendre les émotions ; exprimer les émotions
Corrigé proposé

Réponse : la 1re proposition. Identifier (percevoir) les émotions, les utiliser, les comprendre et les réguler (gérer).

(Q8) Les fonctions des émotions sont très importantes. On peut dire que :

  • 1) Dans la fonction adaptative, les émotions mobilisent l'organisme pour l'action
  • 2) Dans la fonction motivationnelle, les émotions facilitent l'apparition de comportements émotionnels
  • 3) Dans la fonction sociale, les émotions favorisent tous les comportements
Corrigé proposé

Réponse : la 1re proposition. Dans sa fonction adaptative, l'émotion prépare et mobilise l'organisme pour l'action, par exemple la peur pour la fuite.

(Q9) Les facteurs qui interfèrent avec l'écoute active sont :

  • 1) Impatience ; préoccupation ; indifférence
  • 2) Préoccupation ; indifférence ; dissiper les inquiétudes
  • 3) Indifférence ; impatience ; concentration
Corrigé proposé

Réponse : la 1re proposition. Impatience, préoccupation, indifférence.

5

(Q10) Énumérez deux lois de la communication et expliquez-les. (2 points)

Corrigé proposé

Les lois de Watzlawick (école de Palo Alto) :

  • On ne peut pas ne pas communiquer. Tout comportement, même le silence, est un message.
  • Toute communication a un contenu et une relation. Le niveau de la relation (comment le message est dit, ce qu'il dit de la relation) englobe et qualifie le contenu.
  • La relation dépend de la ponctuation des échanges.
  • La communication est digitale (verbale) et analogique (non verbale).
  • Les échanges sont symétriques ou complémentaires.

On en cite deux en les expliquant.

6

(Q11) Énumérez deux obstacles à la communication et expliquez-les. (2 points)

Corrigé proposé

Par exemple :

  • Les préjugés et stéréotypes : ils filtrent et déforment le message reçu.
  • Le jargon technique : il rend le message incompréhensible pour le patient.
  • Le bruit et les distractions, ou un environnement inadapté.
  • Les émotions : anxiété, douleur, colère.
  • Les jugements et interprétations hâtifs.
  • L'écoute sélective et le manque de feedback.
  • Les différences culturelles ou linguistiques et les déficits sensoriels.

(Q12) Le style agressif de communication :

  • 1) Cherche à atteindre ses objectifs en attaquant les autres ; considère que « l'attaque est la meilleure agression »
  • 2) Interrompt souvent les autres ; cherche à atteindre ses objectifs en attaquant les autres
  • 3) Interrompt souvent les autres ; résout les problèmes par une confrontation directe et responsable
Corrigé proposé

Réponse : la 2e proposition. Le style agressif interrompt souvent les autres et cherche à atteindre ses objectifs en les attaquant.

(Q14) Le style assertif de communication :

  • 1) Expose ses idées et interrompt souvent les autres ; établit un contact visuel avec l'interlocuteur 2) Expose ses idées, mais sans attaquer celles des autres ; interrompt souvent l'autre personne 3) Expose ses idées, mais sans attaquer celles des autres ; est flexible
Corrigé proposé

Réponse : la 3e proposition. Le style assertif expose ses idées sans attaquer celles des autres et reste flexible.

9

(Q16) Les différents types de sourire et leur signification (associez chaque sourire à sa signification ; les propositions du menu déroulant n'ont pas été conservées) :

  • Duchenne smile : …
  • Social smile : …
Corrigé proposé
  • Sourire de Duchenne : sourire authentique et spontané, qui exprime une joie réelle. Il contracte le grand zygomatique et l'orbiculaire des yeux, ce qui plisse les yeux (« pattes d'oie »).
  • Sourire social : sourire volontaire, de politesse ou de convention sociale. Seule la bouche (zygomatique) bouge, sans participation des yeux.
10

(Q17) Les gestes adaptateurs sont les auto-adaptateurs et les adaptateurs centrés sur les objets. Définissez chacun (les propositions du menu déroulant n'ont pas été conservées) :

  • Adaptateurs centrés sur les objets : …
  • Auto-adaptateurs : …
Corrigé proposé
  • Adaptateurs centrés sur les objets : manipulation d'objets sans but instrumental (jouer avec un stylo, des clés, une bague). Ils traduisent souvent la tension ou l'anxiété.
  • Auto-adaptateurs : gestes de contact avec son propre corps (se gratter, se toucher les cheveux ou le visage, se frotter les mains). Ils servent à réguler ses émotions, l'anxiété ou l'inconfort.
