PNF — diagonales de mouvement

Pratique 2 — fiche de révision

L'ESSENTIEL

  • Membre supérieur — 1ʳᵉ flexion : flexion + adduction + rotation externe, DR, flexion poignet/doigts1ʳᵉ extension : extension + abduction + rotation interne, DC, extension poignet/doigts.
  • Membre supérieur — 2ᵉ flexion : flexion + abduction + rotation externe, DR, extension poignet/doigts2ᵉ extension : extension + adduction + rotation interne, DC, flexion poignet/doigts.
  • Membre inférieur — 1ʳᵉ flexion : flexion + adduction + rotation externe, FD + inversion2ᵉ flexion : flexion + abduction + rotation interne, FD + éversion.
  • Chopping = bilatérale asymétrique vers l'extension (flexion du tronc supérieur avec rotation)Lifting = bilatérale asymétrique vers la flexion (extension du tronc supérieur avec rotation).
  • Tête et cou — flexion avec rotation : la main du maxillaire est du côté de la rotationextension avec rotation : la main du maxillaire est opposée à la rotation.
