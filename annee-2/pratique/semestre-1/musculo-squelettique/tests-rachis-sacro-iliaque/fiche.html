Tests spécifiques — rachis et sacro-iliaque

Tests 3 — fiche de révision

L'ESSENTIEL

  • Rachis cervical — signes rendant un test positif : perte d'équilibre, paresthésie labiale, paresthésies des membres, nystagmus, instabilité, douleur.
  • Sharp-Purser → instabilité AP du rachis cervical supérieurSpurling (compression) → protrusion discale ou compression radiculairedécoaptation → lésion capsulo-ligamentaire.
  • Lombaire : Valsalva et test de compression → protrusion/compression radiculaireLasègue 35-70°Bragard (SLR + flexion dorsale)FNST → L2-L4.
  • Stork Standing Test → fracture de stress, spondylolisthésis.
  • Sacro-iliaque : Piedallu, Gillet, flamant rose, Gaenslen, Nachlas, gaping antérieur et postérieur.
  • Instruments : NDI, Oswestry, Roland-Morris, Quebec Back Pain.

2. Rachis cervical

Les tests cervicaux sont positifs si le patient présente un ou plusieurs des symptômes suivants : perte d'équilibre · paresthésie labiale · paresthésies des membres supérieurs ou de tous les membres · nystagmus · instabilité · douleur.

6. Valeurs diagnostiques — rachis et sacro-iliaque

SnNout : un test très sensible, quand il est négatif, permet d'écarter la pathologie. SpPin : un test très spécifique, quand il est positif, permet de la confirmer. Aucun test isolé ne suffit : c'est la combinaison (cluster) qui fait le diagnostic.
