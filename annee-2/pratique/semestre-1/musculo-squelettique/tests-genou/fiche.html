Tests spécifiques — genou

Tests 5 — fiche de révision

L'ESSENTIEL

  • Schéma capsulaire du genou : flexion (+++), extension (+)racines L3, L4.
  • Angle Q : hommes 10-15°, femmes 10-19° ; la déviation de la rotule doit être ≤ 0,5 mm de différence.
  • Épanchement : Patellar Tap Test → importanttest de flottement → minime.
  • LCA : tiroir antérieur, Lachman (30°), Lachman actif, signe du Levier — les deux derniers utiles en conditions aiguësLCP : tiroir postérieur, Godfrey.
  • Ménisques : Apley compression, McMurray, Thessaly — rotation externe → ménisque interne, rotation interne → ménisque externe.
  • Blocage : varie dans les amplitudes entre -10° et -45°, avec un end-feel élastique.

7. Valeurs diagnostiques des tests du genou

SnNout : un test très sensible, quand il est négatif, permet d'écarter la pathologie. SpPin : un test très spécifique, quand il est positif, permet de la confirmer. Aucun test isolé ne suffit : c'est la combinaison (cluster) qui fait le diagnostic.
